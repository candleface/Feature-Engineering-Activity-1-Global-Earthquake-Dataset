# Project description
A dataset of Earthquakes from the year 2020 to 2026 was taken from Kaggle
The dataset had missing values, NULL, NaN nd so on.
Python libraries like pandas, numpy, sckit-learn, seaborn, and matplotlib were used to:
              understand the data, data imputation, and data transformation.
Further it was found that most earthquakes range from 5.0 to 5.5 in magnitude regardless of the type of measurement(the units it was measured in).
